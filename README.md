Air Quality Monitoring System - MQTT Simulation

Project ini merupakan simulasi sistem pemantauan kualitas udara berbasis Cyber-Physical Systems (CPS) dengan menggunakan protokol MQTT.

## Prasyarat & Instalasi
1. Pastikan **Python 3.x** sudah terinstall di komputer Anda.
2. Install MQTT Broker (Eclipse Mosquitto). 
   - Pastikan service Mosquitto sudah running secara lokal (`localhost:1883`).
3. Install library `paho-mqtt` melalui terminal/CMD:
   ```bash
   pip install paho-mqtt
